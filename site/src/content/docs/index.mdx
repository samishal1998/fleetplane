One static binary · No agents on your VMs · Open source, built in Go

```bash
curl -fsSL https://raw.githubusercontent.com/samishal1998/fleetplane/main/install.sh | sh
fleetplane serve --config config.yaml
fleetplane acquire --class ci-large --ttl 90m
```

## Everything you need to run a fleet. Nothing you have to babysit.

Fleetplane drives your providers' APIs directly and keeps its own journal of every mutation — so the fleet converges even when the process, the network, or the cloud misbehaves.

<CardGrid>
	<Card title="Agentless" icon="laptop">
		Nothing to install on your VMs. Fleetplane talks only to provider APIs — no daemons, no agent upgrades.
	</Card>
	<Card title="Crash-safe by construction" icon="approve-check">
		Every provider call is journaled first, so a `kill -9` mid-provision never duplicates a server. Ambiguous outcomes are verified, never guessed.
	</Card>
	<Card title="Reuse before create" icon="random">
		Acquisitions lease idle capacity first and only create new machines on demand — and billing-aware scheduling reuses capacity you already paid for.
	</Card>
	<Card title="Multi-provider" icon="puzzle">
		One kernel drives Hetzner Cloud, DigitalOcean, AWS, GCP and Docker, plus a deterministic fake. The provider SDK is one small interface.
	</Card>
	<Card title="Pools and a warm tier" icon="server">
		Declare replica counts and Fleetplane holds them. Where stopped machines bill at storage price, idle machines are parked and restarted in seconds.
	</Card>
	<Card title="Batteries included" icon="rocket">
		Web dashboard, Prometheus metrics, token auth, declarative `apply` and `cloud-init` bootstrap — one binary, SQLite underneath.
	</Card>
</CardGrid>

## Three steps to a converged fleet

<Steps>

1. **Configure a provider and classes.** Point one YAML file at a provider and define classes — reusable machine templates with a server type and image. Credentials are always `secret://` references, never literals.

2. **Declare pools — or just acquire.** Declare pools with replica counts for warm capacity, or go straight to `fleetplane acquire` for a leased machine with a TTL. Both compile onto the same imperative API.

3. **Fleetplane converges, leases and reclaims.** The reconciler leases idle machines before creating new ones, replaces failures, and deletes what nothing uses anymore.

</Steps>
